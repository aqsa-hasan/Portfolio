# Aqsa Bi Portfolio

A professional graduate portfolio for **Aqsa Bi**, an Operations Support Executive. The site presents personal information, professional summary, key skills, education, work experience, and achievements in a responsive heart-inspired visual theme.

## Features

- Responsive layout for mobile, tablet, and desktop
- Fixed header with navigation shortcuts
- Right-side sliding navigation menu with close controls
- Pink heart-inspired theme with animated background hearts
- Animated profile heart with delayed text reveal
- Hover heart burst effect around the profile heart
- Scroll-triggered section reveal animations
- Typewriter hero heading with reverse erase loop
- Contact, email, phone, and LinkedIn links
- Custom pink heart browser favicon

## Tech Stack

- React 19
- Vite
- CSS animations and responsive media queries
- Intersection Observer API for scroll animations
- Oxlint

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Run lint checks:

```bash
npm run lint
```

Preview the production build:

```bash
npm run preview
```
